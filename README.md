# atelier

クリスタ（CLIP STUDIO PAINT）で描いたイラストのローカル管理を補助するツールです。

**セルシス社とは関係のない非公式ツールです。Windows 専用です。**

ざっくり言うと、こうなります。

**整理前** — 保存フォルダは、気づけばこう

```
ほぞんばしょ\
├─ 新規キャンバス.clip
├─ 新規キャンバス(2).clip
├─ かんせい.clip
├─ ほんとにかんせい.clip
└─ さいしゅう_これで最後.png
```

**整理後** — 完成した絵が、完成日とタイトルの名前で自動的に並ぶ

```
works\
├─ オリジナル\
│   ├─ 20260801-ねこ\
│   │   ├─ 20260801-ねこ.clip
│   │   └─ 20260801-ねこ.png
│   └─ 20260812-うみべ\ …
└─ 版権\
    └─ グループ名\ …
```

やることは、完成した絵にチェックを入れてタイトルを打つだけ。フォルダ作りも日付もリネームも機械がやり、しまい忘れや原本の消失は点検役が見つけて教えてくれます。書き出した画像は `.clip` と同じフォルダに同じ名前で一緒に置く決まりです——入れるのは自分、入れ忘れを見張るのは機械。

- **人間がやること**: 絵を描く、タイトルを決める、完成したと判断する
- **機械がやること**: フォルダを掘る、日付を付ける、命名規則に従ってリネームする、異常を検知する

インストールは不要です。Windows に最初から入っているものだけで動きます。ターミナルを開く必要も、コマンドを覚える必要もありません。

## 導入

入手のしかたは2通りあります。

**A. ZIP でもらう**

1. このページの「Code」→「Download ZIP」を押す
2. ZIP を好きな場所に解凍する

**B. Git でもらう**（Git を使えるならこちらが楽です。更新も `git pull` で済みます）

```bash
git clone https://github.com/arinansamo/atelier.git
```

どちらの場合も、そのあとは共通です。

1. `setup.bat` をダブルクリックする
2. 「絵をどこに置きますか」と聞かれるので、フォルダを選ぶ

最初に選ばれているのは **atelier フォルダ自身**です。そのまま OK を押すと、ツールと絵が同じフォルダに同居します（下の「フォルダ構成」の A）。別のフォルダや別のドライブを選べば、ツールと絵を分けて置けます（同 B）。どちらでも動作は同じです（あとから変えたくなったときは「絵の置き場を変える」を見てください）。

> [!NOTE]
> はじめて実行するとき、警告が出ることがあります。
>
> - 「WindowsによってPCが保護されました」→「詳細情報」→「実行」の順にクリック
> - 「セキュリティの警告」→「開く」を押す
>
> どちらも、インターネットからダウンロードしたファイルに Windows が出す通常の警告です。

## フォルダ構成

**A. setup でそのまま OK した場合（ツールと絵が同居）**

```
atelier\
├─ setup.bat など           ツール本体
├─ root.txt                 絵の置き場の住所メモ（setup が作る）
├─ wip\                     作業中の置き場。クリスタの保存先にする（中は自由）
└─ works\                   完成品の保管先
    ├─ オリジナル\           グループフォルダ（自由に作れる棚）
    │   └─ 20260801-ねこ\
    │       ├─ 20260801-ねこ.clip
    │       └─ 20260801-ねこ.png   書き出した画像（.clip と同じ名前で）
    └─ 版権\
        └─ グループ名\       グループは入れ子にもできる
            └─ 20260812-タイトル\
```

**B. setup で別のフォルダを選んだ場合（ツールと絵が別居）**

```
atelier\                    ツール本体だけ
├─ setup.bat など
└─ root.txt                 下の場所を指す

D:\illust\                  選んだ絵の置き場（例）
├─ wip\
└─ works\
    └─ （中身は A と同じ構成）
```

`wip` の中は完全に自由です。命名規則はなく、描きかけ・没・資料など何を置いても構いません。ツールが `wip` にすることは、organize のときに `.clip` の一覧を見せることだけで、勝手に動かしたり片付けたりはしません。規則があるのは `works` の中だけです。

## 用語

`works` の中に登場するのは、この2種類のフォルダだけです。

| 用語 | 名前の形 | 目的 |
|---|---|---|
| **作品フォルダ** | `YYYYMMDD-タイトル`（日付は完成日。例: `20260801-ねこ`） | 1作品を1フォルダで保管する。`.clip` と書き出した画像は必ずこの中に入る |
| **グループフォルダ** | 自由（例: `オリジナル`、`版権\グループ名`） | 作品フォルダを好きに束ねるための棚。入れ子にできる。作らずに `works` 直下へ作品を置いてもよい |

## 使い方

1. クリスタの保存先を `wip` フォルダにして、いつも通り絵を描く
2. 完成したら `organize.bat` をダブルクリックする

`wip` にある `.clip` の一覧が1枚の窓に表示されます。完成したものにチェックを入れ、タイトルとグループをその場で直して OK を押すだけ。チェックを入れなかったもの（描きかけなど）は何もされず、そのまま残ります。グループは行ごとのドロップダウンから選ぶか、新しい名前をそのまま打ち込みます（フォルダは機械が作ります）。`版権\グループ名` のように `\` で区切れば、グループの中にグループを作ることもできます。完成日付きのフォルダに整理され、日付は `.clip` の最終更新日から取るので、まとめて後から整理しても正しい日付が付きます。

このツールが動かすのは `.clip` だけで、画像には一切触れません。書き出した画像は **`.clip` と同じ名前（拡張子だけ違う形）** で作品フォルダに入れておきます。例: `20260801-ねこ.clip` → `20260801-ねこ.png`。クリスタの書き出しは元のファイル名が既定なので、普通に書き出せばこの形になります。

改訂版や差分を作るときは、作品フォルダの中で `.clip` をコピーし、`20260801-ねこ-モザイク無し.clip` のように**フォルダ名に好きな接尾辞を足した名前**にします。差分の画像も同じく `20260801-ねこ-モザイク無し.png`。同じ名前の画像が無い `.clip` は check が名指しで教えてくれます。

## 点検（check）

ときどき `check.bat` をダブルクリックすると、`works` の中を点検して結果を日本語で報告します。報告するだけで、自動修正はしません。`wip` の中は何をしていても口を出しません。

- **原本が見つかりません** — 作品フォルダに `.clip` が無い（最重要。画像だけ残して原本を消した事故）
- **書き出し忘れ** — `.clip` と同じ名前の画像が無い（差分も1つずつ数えます）
- **フォルダ名が規則と違います** — 「YYYYMMDD-タイトル」の形になっていない
- **ファイル名がフォルダ名と違います** — `.clip` の名前がフォルダ名で始まっていない
- **置き場所が違うファイル** — 作品フォルダに入らず、グループの階層に直接転がっている `.clip` や画像
- **日付が未来です** — フォルダ名の完成日が未来（打ち間違い）

もっと細かく見たい日は `check-strict.bat` をダブルクリック。ふだんの点検に加えて、次のような「意図的かもしれないもの」も水色で一覧します。直せという意味ではありません。

- `.clip` でも画像でもないファイル（メモなど）
- `.clip` が画像より後に更新されている作品（書き出し直し忘れかも）
- 作品フォルダの中のフォルダ、空のグループフォルダ、同じ名前の作品の重複


## 絵の置き場を変える

もう一度 `setup.bat` を実行して別のフォルダを選ぶと、ツールが見る絵の置き場が切り替わります。

ただし、**切り替わるのは参照先だけで、絵そのものは自動では運ばれません**。すでに絵がある場合は、`wip` と `works` をエクスプローラーで新しい場所へ移したうえで、`setup.bat` で選び直してください（移すのと選び直すのは、どちらが先でも構いません）。

置き場を離れた場所にした場合は、`wip` フォルダのショートカットをデスクトップに置いておくと保存先の指定が楽になります。

## 安全について

> [!TIP]
> このツールが自分から絵を消したり、上書きしたりすることはありません。

- できる操作は「フォルダを作る」と「`.clip` を移動する」の2つだけです。削除する命令はコードのどこにもありません
- 移動先に同じ名前のファイルが既にある場合、移動は失敗して元のファイルがそのまま残ります（上書きは起きない仕様です）
- organize はチェックを入れたものしか動かさず、実行前に移動先の一覧を表示して確認を挟みます
- check は見て報告するだけで、ファイルには一切触れません
- ツールが書き込むファイルは、絵の置き場を記録する `root.txt` ただ1つです

## 開発メモ

利用者が触る3つの `.bat` は、`tools\` にある同名の PowerShell スクリプトを呼ぶだけの薄いランチャーです。絵の置き場は `setup` が書く `root.txt`（ツールと同じフォルダに置かれる、絶対パス1行のテキスト）から読みます。

実装の決めごと:

- Windows に最初から入っている Windows PowerShell 5.1 を対象にする（「インストール不要」を成立させる唯一の実行系のため）。外部モジュールも PowerShell 7 固有の構文も使わない。バッチは常に 5.1 を呼ぶので、7 が入っている環境でも挙動は変わらない
- `.ps1` と `root.txt` は UTF-8 (BOM付き)。BOMが無いと PowerShell 5.1 が日本語を Shift-JIS として読んで化ける
- `.bat` からは `-ToolDir "%~dp0."` と末尾ドット付きでパスを渡す（`"%~dp0"` のままでは末尾の `\` が閉じ引用符を壊す）
- `.clip` の中身は読まない・書かない。画像には一切触れない。破壊的操作の前には必ず確認を挟む
- 検査は「今の状態」だけを見る。過去の経緯や旧仕様の知識を判定に持ち込まない
- 名前の照合は完全一致だけ。前方一致などの当て推量はしない
- 入力はGUIダイアログ（IMEがコンソールで崩れるため）、進捗と報告はコンソール、エラーは日本語1行で
- パスに日本語・空白が入る前提で書く（`-LiteralPath` を使う）
